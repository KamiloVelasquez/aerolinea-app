# ✈️ Airline Reservation System

Sistema completo de reservas de vuelos desarrollado con arquitectura fullstack, enfocado en escalabilidad, experiencia de usuario y gestión eficiente de datos.

---

## 🚀 Descripción

Airline Reservation System es una aplicación web que permite gestionar todo el flujo de reservas de una aerolínea:

* Búsqueda de vuelos
* Gestión de usuarios
* Reservas en tiempo real
* Administración de datos de vuelos
* Visualización de información para toma de decisiones

El sistema está diseñado siguiendo buenas prácticas de desarrollo y una arquitectura modular que permite escalar a nivel empresarial.

---

## 🧠 Problema que resuelve

Muchas aplicaciones de reservas no integran correctamente:

* Procesamiento eficiente de datos
* Experiencia de usuario fluida
* Escalabilidad del sistema

Este proyecto aborda estos retos mediante una solución moderna basada en tecnologías web y bases de datos optimizadas.

---

## 🏗️ Arquitectura

Aplicación basada en arquitectura **cliente-servidor (fullstack)**:

Frontend → React
Backend → Node.js + Express
Base de datos → MySQL

Flujo:

Usuario → Frontend → API REST → Base de datos → Respuesta al usuario

## ⚙️ Instalación y ejecución

### 1. Clonar repositorio

```bash
git clone https://github.com/KamiloVelasquez/tu-repo.git
cd tu-repo
```

### 2. Backend

```bash
cd backend
npm install
npm run dev
```

### 3. Frontend

```bash
cd frontend
npm install
npm start
```

### 4. Base de datos

* Crear base de datos en MySQL
* Importar script SQL
* Configurar variables de entorno

---

## 🔐 Variables de entorno

Crear archivo `.env` en backend:

```env
DB_HOST=localhost
DB_USER=root
DB_PASSWORD=tu_password
DB_NAME=airline_db
PORT=3000
```
